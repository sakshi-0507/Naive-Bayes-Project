# Naive Bayes Classification

This project is a **Machine Learning classification project** using the Naive Bayes algorithm.

I tried different Naive Bayes models and compared their training and testing accuracy to see how they perform on the dataset.

### Results

| Model         | Training Accuracy | Testing Accuracy |
| ------------- | ----------------: | ---------------: |
| Naive Bayes   |            56.85% |           55.65% |
| Naive Bayes 1 |            62.30% |           64.52% |
| Naive Bayes 2 |            63.31% |       **66.94%** |

The second model gave the highest testing accuracy of **66.94%** among the models I tested.

### Tools Used

Python, Pandas, NumPy, Scikit-learn, Jupyter Notebook

### Project Goal

The main goal of this project was to understand how Naive Bayes works and compare different versions of the model on the same dataset.
